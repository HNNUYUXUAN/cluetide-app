# 依赖与许可

ClueTide 自有源码采用根目录 [MIT License](../../LICENSE)。Python、npm 与构建后端依赖保留其各自的许可和作者署名，按 [依赖与许可索引](依赖与许可索引.json) 定位到 `licenses/` 内的原始许可文件。

索引记录 Python 锁定依赖、npm 锁文件与实际安装元数据，并区分开发、测试、运行、可选平台依赖及构建后端。共保留 203 份许可与署名原件；每份记录文件路径、字节数及 SHA-256。未安装的 npm 可选平台包仅依据锁文件记录许可声明，其许可正文核读范围在索引中说明。

公开案例中的项目自写事实摘要保留原始页面或固定源码链接。上游网页与合约源码的使用继续依其原站条款；链接摘要和以太坊 RPC 观察的许可范围与本项目自有代码分开理解。
