# Uniswap 提案 93 公开证据快照

Ethereum 区块 24106368–24106388，UNI Treasury→dead 的 1 亿 UNI Transfer；治理提案及历史 totalSupply getter 作为独立观察。

`rpc.json` 是运行时使用的公开 RPC 快照。`raw/` 保存公开请求和响应原字节，采集记录区分成功、空结果与错误。`sources.json` 为项目自写事实摘要，包含来源署名、原链接、定位、观察日期与实际阅读范围。

`fixture-manifest.json` 为本目录当前文件的大小与 SHA-256 索引。其校验确认字节一致性；RPC 结果属于提供者报告的观察，来源解释与链上原始事实应按各自范围复核。
